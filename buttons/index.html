Buttons

Add btn to a link or button. Put buttons inside buttons to centre them and space them out, and add a colour class for the background.

ClassDescription
buttonsCentres the buttons inside it. On small screens they wrap two per row
buttons.one-lineOn small screens, puts one button per row instead
btnThe button itself
btn.hoverFloats the button upwards on hover
btn.hover-scaleGrows the button on hover
btn.hover-scale-insetShrinks the button on hover
btn.animationSlides the buttons in one after another when the page loads
btn.no-dark-hoverTurns off the darkening on hover
btn.{colour}-dropshadowKeeps the drop shadow while hovering

Source: scss/components/_buttons.scss
