Utilities

Single-purpose classes that can be combined on any element.

ClassDescription
boldBold text
italicItalic text
text-centerCentre the text
text-leftAlign the text left
text-rightAlign the text right
no-borderRemove the border
no-border-radiusRemove rounded corners
no-box-shadowRemove the box shadow
no-marginRemove all margins
no-paddingRemove all padding
no-backgroundMake the background transparent
no-selectStop the text from being selected
center-displayCentre a block element and its text
center-flexCentre the children with flexbox
