Modesta

A responsive CSS framework with built-in dark and light theme, shipped as a single modesta.css

Getting started

Download modesta.css from the latest release and add it to your page:

<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <link href="modesta.css" rel="stylesheet">
  </head>
  <body>
    <section class="container">
      <h1>Hello there</h1>
    </section>
  </body>
</html>

Or skip the download and link the latest version straight from the docs site:

<link href="https://modesta.alexflipnote.dev/index.css" rel="stylesheet">

This always serves the latest version.

Pages use the dark theme by default. Add light-theme to <body>, or to any element, to switch to the light one.

Documentation

Every component, with live examples, is documented at modesta.alexflipnote.dev

Development

Requires Node.js 20 or newer. Run npm install once, then:

CommandWhat it does
npm run buildBuild the docs site into dist/ with mothwing, dist/index.css is the compiled Modesta
npm run devServe the docs at http://localhost:8080 and rebuild on every change
npm run checkFail if a class in modesta.css is not documented
npm run lintCheck the SCSS with stylelint

Docs are written next to the code as /// comments, see docs/lib/modesta.js for the format, and the site around them is in docs/. Every push builds it, publishes dist/ to the gh-pages branch, and releases the CSS, so dist/ is never committed.

To release a new version, change version in package.json.
