Grid

A 12 column grid built on flexbox. Put columns inside flex-grid and give each one a width out of 12, or leave the number off to share the row equally.

ClassDescription
containerCentres the page content, up to 1100px wide
flex-gridA row of columns
col-{size}-{n}Column that is n twelfths wide
col-{size}Column that shares the row equally with the other columns

Breakpoints

xs columns apply at every size above phone width. The other sizes only start at their breakpoint and are full width below it, so they can be combined:

SizeClassesApplies
xscol-xs-*Above 550px
smcol-sm-*From 551px
mdcol-md-*From 751px
lgcol-lg-*From 1101px

At 550px and below, every column is full width.

Gutter

Columns sit --modesta-gutter apart, 1rem unless you set it, across and between rows. Columns wrap onto the next row when they add up to more than 12.
