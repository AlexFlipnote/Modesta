Themes

Pages use the dark theme by default, no class needed. Add light-theme or dark-theme to any element to switch it and everything inside it, so one page can mix both.

ClassDescription
dark-themeDark colours for this element and everything inside it (the default)
light-themeLight colours for this element and everything inside it
auto-themeFollows the system, light colours when it asks for light and dark otherwise. Put it on html for the whole page

Theme colours

Each theme is a set of CSS variables:

Variable:root,.dark-theme.light-theme.auto-theme
--modesta-highlight#181818#f5f5f5#f5f5f5
--modesta-primary#282828#ececec#ececec
--modesta-secondary#303030#d9d9d9#d9d9d9
--modesta-text#fff#000#000

To change a theme's colours without recompiling, override its variables on the same selector:

:root, .dark-theme {
  --modesta-primary: #1b2838;
  --modesta-secondary: #2a475e;
}

These classes use the current theme's colours:

ClassDescription
highlight-bgHighlight colour as the background
primary-bgPrimary colour as the background
secondary-bgSecondary colour as the background
highlight-textHighlight colour as the text colour
primary-textPrimary colour as the text colour
secondary-textSecondary colour as the text colour
theme-textThe theme's text colour
